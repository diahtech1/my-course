# COURSE OUTLINE
Here is your exact, day-by-day structural blueprint. This ensures that when you open your computer every morning, you know exactly what concept to search for, what project feature to build, and when to move to the next step without any confusion.

## The Everyday Action Checklist
Before looking at the curriculum, memorize this 90-minute daily execution framework:

**First 20 Mins**: Go to YouTube, Google, or documentation. Search the exact Daily Concept Topic listed below. Watch/read one short guide just to understand the theory.

**Next 10 Mins**: Close the video. Open your notepad. Write down the Inputs, Transformations, and Outputs (ITO) for that day's task in plain English.

**Next 40 Mins**: Open your code editor. Use your AI assistant (Claude/ChatGPT/Cursor) to generate code based only on your plain-English blueprint. Paste it in and run it.

**Last 20 Mins**: Highlight the working code. Ask the AI: "Explain lines X and Y to me. What are two edge cases where this code will fail, and how do we prevent them?"

## Month 1 & 2: Frontend & Structural Logic (Phase 1 Blueprint)
**Week 1**: Core Computational Logic (Language: Python)

**Day 1** Concept: Variables and Basic Data Types (Strings, Integers, Floats, Booleans).

**Daily** Task: Write a script that takes a user's name and birth year, calculates their age, and prints a customized greeting.

**Day 2** *Concept: Conditional Statements (if, elif, else).

**Daily** Task: Build a script that checks a user's bank balance and item price, then prints "Approved" or "Denied" based on funds.

**Day 3** Concept: Loops (for and while).

**Daily** Task: Create a program that loops through a list of 10 numbers and prints only the even numbers.

**Day 4** Concept: Functions (Inputs/Parameters and Outputs/Return Values).

**Daily Task** : Turn your Day 2 bank check logic into an isolated, reusable function that returns True or False.

**Day 5 Concept**: Error Handling (try, except).

**Daily Task**: Build a calculator function that divides two numbers, but safely catches the error if a user tries to divide by zero.

**Weekend Project Milestone**: The Text File Filter. Create an algorithm that reads a messy list of users from a plain .txt file, filters out users below a certain age, and saves the clean results into a brand new text file.
